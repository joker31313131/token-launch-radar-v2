How the value is scored

Every implied value is a pure function of the snapshot's own figures. No protocol name is special-cased; the same function scores every row.

  1. M(category) — the median market-cap-to-TVL ratio of the token-bearing protocols in the same category (at least 5 of them), otherwise the global median across all token-bearing protocols. Clamped to [0.05, 0.75].
  2. Growth — 1 + 0.5 × clamp(7-day TVL change, −40%, +60%) ÷ 100. An unreported change counts as 0.
  3. Maturity — 0.7 + 0.3 × min(age in days, 730) ÷ 730, from the listing date to the snapshot date. An unknown listing date counts as 365 days.
